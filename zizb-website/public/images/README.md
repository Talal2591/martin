# Bilder-Struktur

Echte Fotos hier ablegen (WebP, sinnvoll komprimiert). Die Platzhalter im Code
(`<ImagePlaceholder note="..." />` bzw. `<!-- TODO Bild: ... -->`) benennen pro
Stelle das gewünschte Motiv.

```
images/
├── og-default.webp          # Share-Bild 1200x630 (Praxis-Außenansicht oder Empfang)
├── praxis/
│   ├── empfang.webp         # Empfangsbereich, ruhig & hell
│   ├── behandlungszimmer.webp
│   ├── aussenansicht.webp   # Eingang Egestorfer Str. 4 (auch für Anfahrt)
│   └── wartebereich.webp
├── labor/
│   ├── meisterlabor.webp    # Zahntechniker am Arbeitsplatz
│   └── cadcam.webp          # CAD/CAM-Fräse / exocad-Arbeitsplatz
├── team/
│   ├── talal-atassi.webp    # Portrait, 4:5, einheitlicher Hintergrund
│   ├── sami-atassi.webp
│   ├── aleksandra-nasradin.webp
│   └── sarah-hinrichs.webp
└── leistungen/              # optional: je Leistung ein Headerbild 16:9
```
